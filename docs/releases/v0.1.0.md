## 首个公开版本

IMAP-Notify 使用 Rust 同时监听多个 IMAP 邮箱，将新邮件主题、发件人和图标通过一个 Bark 地址推送到 iPhone。

- IMAP IDLE 实时监听，保留未读状态；自动重连并补查同一进程断线期间的新邮件。
- 支持中文主题、账户分组、图标、声音、通知级别与网页邮箱跳转。
- 支持授权码、应用专用密码和可信密码命令；提供离线配置校验与独立 Bark 测试。
- 错误日志脱敏、严格配置校验、非 root systemd 部署。
- 补齐需求、代码审查记录、维护指南和中文 README。

## 下载与运行

根据系统与架构下载对应 `.tar.gz`，使用 `SHA256SUMS` 检查完整性。解压后复制 `config.example.toml` 为 `config.toml`，填写 Bark 地址和邮箱授权码：

```bash
chmod 600 config.toml
./imap-notify -c config.toml --check
./imap-notify -c config.toml --test-bark
./imap-notify -c config.toml
```

发布包覆盖 Linux x86-64、Linux ARM64、macOS Apple Silicon 和 macOS Intel。Linux 包基于 Ubuntu 24.04 构建，要求 glibc 2.39+ 和系统 CA 证书；较旧系统可用 Rust 1.88+ 从源码构建。macOS 包未签名或公证。

## 验证与边界

自动检查包括格式、Clippy、28 项单元/协议测试、2 项 CLI 集成测试、Rust 1.88 兼容性及各发布二进制的 CLI 冒烟检查。真实邮箱和 iPhone 端到端测试需自行执行。

进度仅在内存中保留，进程重启会跳过停机邮件；最终推送失败会记录警告后跳过，超时重试可能重复。当前不支持 OAuth2，也没有 IMAP/密码命令统一应用级超时。
